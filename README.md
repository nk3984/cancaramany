# Can Caramany

Premium private-estate website for **Can Caramany**, Mallorca.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Homepage
- `/properties/property-i`
- `/properties/property-ii`
- `/properties/property-iii`
- `/properties/property-iv`

## Assets

Production imagery belongs in `public/images/can-caramany/`. See that folder’s README for required filenames. Until assets are supplied, the UI shows explicit `IMAGE REQUIRED — …` placeholders.
